Qualify the component proposed in the
[saved-region diagnostic plan](../ilvis0-rotation-gain-prediction/NEXT_PLAN.md).
It verifies linear constraints and box limits with rational arithmetic and
repairs only toward a supplied, independently verified feasible anchor.

Freeze twenty identities: box, strict halfspace, boundary-anchor and point-box
families crossed with axes 0, 18, 25, 42 and 50 in a complete 51-coordinate region.
Each identity performs one declared repair and one exact objective check against
an analytically known answer. Other coordinates remain present. Local tests add
contradictory regions, malformed inputs, signed directions and exact treatment of
binary decimals. A failed or unsupported anchor never becomes a repaired success.

Limits: twenty identities and twenty repairs, zero LP proposals, native calls,
native bounds, aircraft reads, observed fits or protected outcomes. Four workers
use one thread each, with a 60-second cooperative allowance. No retries,
expansion, process signals or completed-study restart. Freeze sources, task
identities, inputs and environment before execution. This qualifies the
mathematical component only; the separately frozen six-case saved diagnostic
must assess what its feasible witnesses establish about the relaxed region.
