# Training-bound outcome

All six generated cases stopped at the same check: the calculation could no
longer guarantee a positive input to a square root. Each preserved 58 training
reports, for 348 reports in total. None completed the required 289 epochs.

This is a failure of the bound calculation over the complete calibration range,
not evidence for or against an Earth model. The source, inputs, partial reports,
failures and resource charges remain preserved. The completed allowance will
not be restarted or expanded.

The [frozen report](README.md) records the original experimental sequence.
The current [prediction protocol](../PREDICTION_VALIDATION.md) takes a different
next step: qualify training-only fitting and observation-free forecasting, then
compare forecasts with unused aircraft positions. Global interval certification
remains separate; neither partial bounds nor forecast sensitivity establish
calibrated confidence.
