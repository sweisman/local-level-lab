processing cases, each with four controls. Preserve the completed sources;
this separately identified candidate changes algebraic bounding only.

   the regrouped point map for every one of 27 normalized parameters, compared

entire query intervals remain inside the short packet records. These are
software fixtures; broad-region controls retain the original flight limits.
No observed-data calibration assumption changes.

per coordinate**; all 27 finite-difference tangent columns agree within
**20 micrometres per normalized parameter** using a fixed 0.002 step; every
probe's Taylor error fits its supplied global remainder plus the declared
10 micrometre arithmetic allowance. That allowance is an assumption, not a
whole-program numerical certificate. All identities must pass. A failure
stops the sequence and blocks dependent comparisons; no retries or threshold
changes are allowed within this freeze.

/ 7,536 reserved bound packet steps**, and 120 cooperative seconds overall.

other identity reserves one bound and four native calls. Charge each call and
bound before execution. One worker reserves four numerical threads. Preserve
each generated input, native output/Jacobian, bound, probe and failure with
source/environment hashes. No original-file reads, Earth-model fits, protected

A pass qualifies this finite mathematical/numerical comparison, not long-record
usefulness, global floating-point coverage or actual receiver-error assumptions.
