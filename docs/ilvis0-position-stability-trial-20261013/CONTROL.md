# Software qualification

The independent controls exercise known interior and boundary optima, nonlinear
curvature, correlated gain/offset parameters, redundant parameters and a 27-parameter
ill-conditioned system. Each has four deterministic starts and at most 200 calls.
Require correct known objectives and predictions, plus accurate parameters where
identifiable. Forty such cases must pass before archival work.

Additional checks distinguish tiny actual motion from large individual prediction
changes, cost increases and nonstationary endpoints. Both per-axis RMS and isolated
peak limits must be enforced. Verify covariance unwhitening against direct native
positions for each physical model. Require charged call accounting, source isolation,
unchanged scientific abstention and a completed-study restart rejection.

The software evidence contains no original-file reads or archival fit starts. It
qualifies the implementation on these controls, not the aircraft data or its uncertainty.
