# Software controls and their limits

The rectangular candidate is checked against independently specified interior,
boundary, redundant, scaled, nonlinear and coupled gain/offset equations. Three
fixed starts test known objectives and observations, with parameter checks only
where the answer is identified. The near-boundary 27-parameter control has a
100-million-to-one singular-value ratio; TRF fails its original stability test
while dogbox passes it unchanged.

Eight independently generated motion controls test increments and receiver
predictions, including transport, bias, gain, timing and background-field cases.
Their software uncertainty is 0.1 m, matching the previous justified fixture;
physical truth tolerances stay unchanged. The archival uncertainty is not changed.

Worker tests check private configuration isolation, authorization before originals,
completed-run refusal and tamper detection for the new tangent artifact. Existing
durable worker/native/ledger tests remain applicable and are run too. These checks
do not establish archive uncertainty, global optima or empirical significance.

The tested candidate requires the fresh bounded correction probe to pass. Three
callbacks alone cannot accept a solution, and unchanged callbacks are not counted
as accepted improvements. No original failed result is relabeled.
