# What the simulated reference counts can resolve

After verifying the reference replay, calculate what its counts allow
under the existing illustrative 5% overall allowance and seven-group
rule. Evaluate every requirement from one qualifying group through
all seven. Keep all original seed IDs in their separate generating
scenarios. Count every unavailable seed and every tie in the upper tail.

Report the smallest possible rank probability and the minimum reference
count if the number of unavailable seeds stays fixed. Where a cutoff is
reachable, report how many available scores may tie or exceed it and
which saved receiver loss the target would have to exceed. This is a
numerical resolution check. The illustration selects no operational
cutoff or group requirement. It uses no actual query, new fit, original
validation run or reserved flight.

Check every available starting-point selection against the earlier
training costs in the verified calibration CSV. This check uses the
published costs rather than the replay worker's result-selection code.
