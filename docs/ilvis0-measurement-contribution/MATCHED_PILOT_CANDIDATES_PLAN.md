# Reserve four candidates for a southern pilot

Use the saved 21-stretch engineering eligibility result without changing
it. Retain both eligible IMU8 recordings to cover the east and south course
sectors. Among eligible IMU21 stretches choose the pair with the largest
difference in mean latitude. The pair must come from distinct conservative
flight groups outside the chosen IMU8 groups. Break ties by the northern
segment ID and then the southern segment ID.

Record candidate identities, original time windows, source hashes, course,
latitude, speed and duration. Mark any group already used by the two-recording
numerical preflight. Use metadata only. This reserve list keeps a later
pilot from being selected using outcomes. It does not freeze a fitting
method, spend a numerical allowance or qualify any new aircraft fit.

The southern list stays fixed if a subsequent engineering study qualifies
northern material. A northern extension would have its own selection and
validation. The receiver-error and joint channel gates still apply.
