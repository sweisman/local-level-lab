# Matched qualification of the rounded trained-source adapter

The physical source-value qualification is complete. This new study checks the
separate adapter that combines those physical intervals with the unchanged
training-derived acceleration constraints and explicit reference rows.

Reuse the same six generated sources, original reference points and saved
physical domains. Reconstruct each original training certificate and verify
its six exact supports. The initial source bridge reports center/row arithmetic
differences and requires the existing nonlinear cap to remain sufficient.
No calibration bound, shared coefficient, reference row or old result changes.

Advance the physical and compiled reference streams through all 1,600 packets.
Apply the adapter at both phases of the fixed packet indices
`0, 15, 63, 127, 511, 1023, 1438, 1439, 1440, 1599`. These cover early, middle,
query-boundary and final prefixes. Preserve all 27 reference columns.

Seal every selected bound before reading the generated calibration. Then
compute that calibration's source stream and compare both its values and
affine errors with the saved allowances. No additional numerical comparison
margin is permitted. The reference centers and rows must match the stated
compiled inputs exactly. Every identity and comparison must pass.

## Finite allowance

- Six identities and six complete physical-source bounds; no retries.
- 19,200 midpoint/end physical bound steps.
- 19,200 compiled source steps: reference and known-calibration streams.
- 36 exact training-support verifications.
- 120 rounded body bounds and 1,440 known-calibration comparisons.
- Four workers, one numerical thread each; four total threads.
- 120 seconds per identity, checked cooperatively; 600 seconds overall.
- Zero full native trajectories, LP proposals, optimizer starts, aircraft
  original reads or protected ESA data.

Sources, inputs, environment, compiler and work reservations are frozen before
launch. Failures and interrupted work remain charged. Passing this study
qualifies the declared trained-source component on generated controls, not
whole native propagation, useful complete prediction widths or observation-error
coverage. The original 24 native controls remain a later gate.
