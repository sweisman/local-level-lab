# Paired gyro differences across time scales

The twelve previously selected same-track recorder pairs were compared using their verified per-second cache. Every one-second difference reproduces the earlier public pair table. Each longer row averages fixed nonoverlapping complete UTC seconds; gaps are not interpolated and no Earth-model fit was run. Values are between-recorder X/Y/Z RMS differences in degrees/hour.

Across the twelve pairs, median X/Y/Z differences fall from 5.46/10.04/2.37°/h at one second to 0.11/0.46/0.16°/h at one minute. Pairs are related recordings, not twelve independent flight replications.
