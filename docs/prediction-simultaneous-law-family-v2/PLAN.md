# Whole-period generated prediction: fresh cohort

The [first frozen cohort](../prediction-simultaneous-law-family/RESULT.md)
closed with 96 package-import failures before any numerical call. Those
sealed outcomes remain unchanged. This study uses a **new independent seed
stream**, a versioned adapter and the corrected package loader. It does not
retry a first-cohort task.

## Frozen question and gate

Can the two-law, training-only whole-period interval union contain every
later coordinate of both physical position and a separate receiver report
on 96 independent generated recordings drawn from the same equal-weight
24-condition mixture? Both fits must pass numerical stopping and physical
prediction screens. Every technical failure counts as a failed recording.
At most one failure qualifies the average-mixture gate: the exact one-sided
95% binomial upper failure bound is then below 5%. Earth-model decisions
remain abstain. No observed-aircraft coverage or per-condition guarantee
can follow from this result.

The route, 2-minute duration, 300 Hz IMU, 119 receiver epochs, 200 fit
evaluations per law, physical bounds, two target scopes, affine error-family
union and 95% joint conditional allocation stay as specified in the first
plan. New mixture draw seed: 20261113. New recording noise seeds:
20261113000 through 20261113095. The source, inputs, environment, tasks,
limits and four workers of one numerical thread each are frozen before launch.
The full run has an eight-hour cooperative wall cap and at least 35 GiB free
space. Each task retains the finite native and construction call limits.

## Release order

1. Pass the real-process package-adapter regression and source-bound software
   and recovery tests.
2. Freeze and run one **short** generated preflight through the actual
   frozen worker loader, with a separate allowance. Verify saved target
   artifacts and method abstention. It may fail numerical stopping at its
   short fit budget; that does not prevent it from proving import and wiring.
3. Freeze and launch the independent 96-recording cohort only after the
   preflight closes successfully. Keep per-task receipts for crash recovery;
   sealed failures stay sealed.
4. Audit only saved evidence: verify hashes, source binding, fits, replay both
   later-target containment scores, count failures by recording, and publish
   the exact confidence bound plus separate condition and target results.

This is a generated software and uncertainty method test, not a repeat of
the original failed cohort and not a real-data Earth-model campaign.

The first short preflight was prepared outside the one-thread numerical guard
and closed with a pre-charge environment mismatch. Its sealed failure remains
preserved. A guarded replacement passed, but the release-test list then changed.
An additional guarded preflight passed, but the release suite then exposed an
environment-dependent test fixture. The final guarded preflight uses the exact
source and plan snapshot required for the 96-recording study. All preflight
attempts remain separately retained.
