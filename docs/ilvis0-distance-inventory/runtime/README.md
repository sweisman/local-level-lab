# Longer-flight candidate inventory

The separate receiver-and-motion scan checked 232 retained recordings. 232 passed strict parsing; 0 were recorded as unsupported or invalid.

The fixed rule found **5 candidate stretches** totaling 55.0 minutes, on **4 conservative recorded-date groups**. Same-day and overlapping recorders count together. These groups are not established independent flights.

The selection uses receiver speed and position, fused-navigation motion screening and raw-stream completeness. It uses no gyro model residuals and makes no Earth-model fits. The original 53-stretch study is unchanged.

The [candidate table](candidates.csv) gives each stretch’s time, distance, speed, endpoints, source and date group. The [file ledger](files.csv) includes sources with no candidate and sources that failed strict decoding.

The next step is to verify flight provenance and model information for these candidates before deciding whether any can contribute to an independent uncertainty study. This inventory alone establishes no prediction coverage or Earth-model detection.
