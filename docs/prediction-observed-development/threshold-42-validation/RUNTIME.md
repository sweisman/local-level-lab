15-state changing-drift law, a wider 4.2 standardized-error threshold and a
one-failure-per-stratum gate before this cohort ran. One numerical worker
used one thread and completed **256/256** tasks in 1,094 seconds, with zero
technical errors and no native aircraft calculation. A source/environment
freeze, charge journal, task receipts and reboot recovery policy were in
place before launch; no recovery task was needed.

The [saved-only audit](RESULT.md) recomputes every later score from its
forecast and residual. It found **1/128** whole-history exceedance without
the generator's vibration and **0/128** with it. The exact 97.5% upper failure
bounds are 4.28% and 2.84%, respectively, so the new generated gate passed.
The median final per-coordinate half-width is 29.57 m.

This result qualifies the **new threshold only for the specified generated
histories**. The earlier 3.635-threshold study remains a failed gate.
Neither study establishes coverage for a real aircraft or makes an Earth-model
decision. The seven reserved ESA flight groups remain unopened.
