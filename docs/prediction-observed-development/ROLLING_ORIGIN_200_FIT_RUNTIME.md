# ESA earlier-origin fit evidence

This sealed study contains the two fixed IMU error-law fits for receiver
reports 0–199 and forecasts for reports 200–319. Both fits pass numerical
checks. The fit workers received IMU increments and future report times but
not future receiver positions. The original source, inputs, environment,
charges, results and recovery policy are retained for audit.

This is development on one already opened flight. See the
[interpretation](../ROLLING_ORIGIN_200_INTERPRETATION.md) and
[fixed plan](../ROLLING_ORIGIN_200_PLAN.md). It makes no Earth-model decision.
