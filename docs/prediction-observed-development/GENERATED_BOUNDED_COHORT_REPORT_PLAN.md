# Eight-case cohort reporting rules

Read only the closed, hash-verified cohort. Include **all eight task IDs** in
the denominator, including technical failures. For each technically complete
case, preserve fit convergence, the original coded physical screen, raw
training and later position errors, all-coordinate known-truth interval
coverage, median coordinate span and the fourteen-parameter known-calibration
comparison. Count technical completion, numerical convergence, coded physical
metric passing, their original joint pass and descriptive interval
containment separately.

The [accuracy-rule correction](GENERATED_ACCURACY_RULE_ERRATUM.md) applies:
the source uses 0.1 m horizontal/vertical RMS and 0.5 m maximum 3D error in
both sections, though the frozen plan's wording says 10 m horizontal RMS.
Show the actual source limits and flag any horizontal result between 0.1 and
10 m. Do not silently reinterpret the source or the frozen plan. Eight
generated cases cannot calibrate an aircraft law or establish a 95% coverage
rate. No new fit, aircraft read or scientific decision is allowed.
