# Saved generated forecast noise-floor audit

Read the eight closed, hash-verified generated cohort tasks. Use each task's
saved earlier-only conditional covariance and its generated truth geometry to
calculate the square root of expected squared horizontal error over the 300
later epochs, **assuming its declared error law and fixed calibration**.
Compare that scale with the inherited 0.1 m horizontal path screen. Also
report the saved raw and conditional-center horizontal errors separately.

This is a diagnostic of whether the deterministic screen is a suitable
noisy-path qualification target. It does not change any frozen study, refit,
estimate real-aircraft error, establish conditional coverage, or make an
Earth-model decision. All eight task identities remain in the denominator.
