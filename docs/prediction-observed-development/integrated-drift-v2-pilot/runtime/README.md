# Fresh-seed changing-gyro-bias pilot evidence

The [frozen 16-task plan](PLAN.md) used an independent generated IMU and
receiver path. Its source/environment manifest, recovery qualification,
charge journal, saved forecasts, later scores and task receipts are retained.
No aircraft original, reserved ESA group or Earth-model fit was used.

All **16/16** technical tasks passed under the original one-thread allowance;
no recovery task was needed. The saved-only [audit](RESULT.md) reproduces the
later scores and records 16/16 whole histories inside the predeclared
conservative simultaneous bound. This is a development pilot, not a
calibrated aircraft prediction range.

The portable evidence bundle and archive publication receipt are stored
beside this page. A verified bundle can be checked with
`~/venv/bin/python -m lll.studies.portable verify <bundle.zip>`.
