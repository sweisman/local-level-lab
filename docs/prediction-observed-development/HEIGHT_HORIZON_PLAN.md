# Locate the changing ESA height error

Use only the two completed forecasts on ESA development recording 187: the
new 600/200 recheck and the previously sealed 800/400 forecast. Do not refit,
select an error law by its scored result, or open any reserved flight group.

Divide each scored period into consecutive, fixed 100-report bins. For every
bin report raw and conditioned signed height error, RMS, nominal marginal
height coverage, conditioning adjustment, and the receiver's recorded speed
and climb rate. Verify the sealed forecast identities and original receiver
input hashes before reading them. The output is a descriptive diagnosis of
**when** the existing error law stops covering height, not a physical-cause
claim or an independent validation.
