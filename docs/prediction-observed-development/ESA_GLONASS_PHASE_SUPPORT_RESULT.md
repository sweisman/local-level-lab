# GLONASS carrier phase covers every pair on the opened flight

All **1,040** half-second pairs retain at least five GLONASS satellites
under the fixed two-band carrier and Doppler screens. The screen
retains **7–9 satellites** per pair. It excludes 1,062 satellite pairs
for missing required observations and five because the satellite
appears at only one endpoint. All other available pairs pass.

Using the receiver clock change already checked on GPS, eight GLONASS
satellites pass both Doppler and dual-phase checks at the exceptional
pair. The slot-dependent frequencies are important because those
satellites do not all transmit at the same frequencies.
[GPS clock-step check](ESA_CARRIER_CLOCK_STEP_RESULT.md)

This verifies phase support. It supplies no receiver position or
geometry result by itself. All original phase observations remain
unchanged, and the reserved groups remained sealed.
