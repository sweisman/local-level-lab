# Generated changing-drift pilot evidence

This package preserves the frozen eight-task study, its source and environment
manifest, charge journal, all conditional forecasts, all later scores and
every task receipt. It contains **no aircraft recording** and made no Earth
model fit. All eight technical tasks passed. The fixed candidate contained
every withheld coordinate in only three of eight generated histories, so it
is not qualified as a complete prediction range for this generated mixture.
