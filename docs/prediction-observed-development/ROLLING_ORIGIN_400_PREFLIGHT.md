# Earlier-origin fit preparation

A preflight on the already saved ESA development recording selects receiver reports 0–399 for fitting and the next 120 times for prediction. Its fit material includes 155,868 IMU packets through the prediction end, but **no later receiver positions**. Both existing error-law assumptions remain in scope.

This only checks the input cut and its hashes. It has made no fit, forecast or Earth-model decision. A source-bound numerical study and interruption-recovery test are still required before launch. This is exploratory work on the already opened development flight; the seven reserved groups remain closed.
