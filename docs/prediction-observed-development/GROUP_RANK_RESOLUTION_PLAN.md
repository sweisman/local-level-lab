# Count usable reference draws for a flight-level test

Use the sealed twelve-case three-candidate comparison. Count reference cases
by generating model, latitude and motion, and IMU noise law. Preserve the
original fit status and do not pool different fixed scenarios. Do not use
the fitted score magnitudes to select a statistic, reference set or threshold.

Report the best possible upper-tail rank within each declared cell and,
as arithmetic only, the optimistic resolution if all four cases per
model had been exchangeable. Compare these with illustrative thresholds
for one, three, five or seven qualifying groups out of seven at 5%.
Give the reference counts that would be required even if the target
were more extreme than every usable draw. Include the effect of one
unavailable draw. This does not choose a confirmation decision policy.

Allow twelve generated task records, one frozen public group ledger,
one numerical thread and zero new fits, native evaluations, new draws,
reference calibration uses or protected flight reads.
