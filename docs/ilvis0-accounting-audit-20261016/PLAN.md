# Interrupted diagnostic accounting

This metadata-only audit preserves the stopped timing diagnostic and determines
which declared identities never started. It performs no native predictions,
optimization or original-recording decoding. One audit batch, no retries.

Verify the retained manifest, both journals, the failure record, eight saved
result envelopes and their native artifacts. Read the valid accounting prefix
explicitly as an interrupted prefix, without rewriting or treating it as a
complete journal. Preserve the incomplete final entry byte for byte.

All nine charged identities retain their full per-identity allowance. Only the
twelve unstarted identities may transfer to a separate continuation freeze:
312 native calls, within the original 546-call identity allowances. Both passing
controls are reused with their hashes; no completed or interrupted identity retries.

The in-place append mechanism admits an incomplete final line after a failed
write. Fault-injection controls reproduce that failure mode. The observed file
ends at 40,960 bytes; available evidence does not establish which operating-system
or storage event caused that particular truncation. The worker's subsequent
accounting read masked the initial exception. No hardware or scientific conclusion
follows from this operational failure.
