# The height correction improves all seven additional groups

A height correction learned from the earlier forecast reduced later
height RMS on **all seven** recording groups outside the original
twenty-group test. It also improved all three groups with passing
numerical fits at both cuts. Horizontal forecast errors stayed identical.

| Group set | Median height RMS before | Median height RMS after | Groups improved |
| --- | ---: | ---: | ---: |
| All seven groups | 4.25 m | 1.97 m | 7/7 |
| Three groups with two passing cuts | 8.91 m | 4.27 m | 3/3 |

Six of seven groups met the fixed accuracy screen both before and
after the correction. The remaining forecast exceeded the 10 m
horizontal RMS limit and remained outside it after the height correction.
All original stopping labels and model comparisons stay in place.

The groups are the three from the original two-cut study and the four
from the first transfer study. Their separation from the twenty-group
test was checked against the frozen 53-stretch grouping ledger. The
correction was saved using earlier forecast errors before the later
errors were opened. It used no new navigation fits.

The result supports a height-specific error model for further testing.
The forecasts all come from the same retrospective archive. These
reports do not identify the cause of the height error, establish a
confidence interval or verify performance on independent flights.
