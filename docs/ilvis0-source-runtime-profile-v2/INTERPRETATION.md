# Where the calculation spends time

Both shortened generated-data profiles completed. They locate substantial cost
in repeated array validation, Python-to-C++ argument conversion and separate
norm calls. The geographic scalar bounds store binary64 endpoints rather than
ever-growing rational expressions.

A separate batched interface will combine those calls while preserving the
existing arithmetic and runtime guards. Its qualification must reproduce the
old values, error ranges and coefficient matrices exactly. These short profiles
do not establish full-recording speed or solve the horizontal-width problem.

The earlier full-history screen remains two completed cases and four time-limit
failures. No aircraft finding changes.
