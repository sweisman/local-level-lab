# Next gate before recorded-data use

The error-budget matrix is a development diagnostic. It does not choose a
smoothing window or declare a real recording scientifically usable.

   window is not permitted. Define an observable motion/support policy separately.
2. Specify the scalar acceleration observable precisely. Mean packet magnitudes
   and the magnitude of a summed body vector are different measurements; neither
   can be treated as an instantaneous exact specific force without an error model.

   averaging controls. Preserve the original integer increments and both clock
   hypotheses where their physical meaning remains uncertain.
4. Combine trajectory truncation, receiver error, nonlinear response and
   acceleration uncertainty consistently before a finite recorded-data comparison.
   A local delta/cubature agreement is not calibrated coverage.
5. Freeze a small motion-selected descriptive diagnostic before any original reads.
   It must compare all candidates, preserve failed windows and withhold a new
   scientific model-selection claim. No nonlinear observed fit or new campaign
   allowance follows automatically from these controls.
