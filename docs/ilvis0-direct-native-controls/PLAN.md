# Qualify the direct source bound in complete native propagation

Install the independently checked direct source/reference-transfer radius.
Intersect it with the existing valid source radii; preserve their source,
reference, domain and packet-phase checks. Do not change measurements,
calibration domains, training constraints, physical models or shared columns.

Repeat the complete 24-identity generated native matrix: all three physical
models, both processing cases, reference centers, stationary poses,
derivative checks and nonlinear containment. Compare every bound against its
sealed integer-arithmetic predecessor. Require identical predictions, all
three coefficient matrices, physical bindings and shared caps, and no larger
coordinate, position, force or lever approximation remainders.

## Separate finite allowance

- 24 identities; 78 native oracle calls and 19,632 oracle packet visits.
- 348 propagation bounds and 67,824 logical bound steps (nine per packet).
- 348 setups each for numerical source rows, domain derivatives and point
  derivatives; 7,536 steps each, plus 7,536 direct-formula packet steps and
  7,536 source-body bounds.
- Four workers with one numerical thread each; four total threads.
- 60 seconds per bound and 600 seconds overall, checked cooperatively.
- No retries, observed fits, aircraft reads, LP proposals, protected ESA data,
  process signals or allowance expansion.

Freeze source, inputs, compiler and environment before launch. Passing this
matrix qualifies the tested native component, not long-history performance,
useful complete prediction widths, whole-program floating execution or
observational confidence. Those require separately frozen checks.
