# Qualify read-only propagation tracing

The saved endpoint certificates identify the longer training and future
propagation allowances as the next targets. A separate tracing implementation
records existing intermediate values; it changes no bounding formula, center,
calibration domain, coefficient, observation allowance or acceptance rule.

Check all three candidates, both processing assumptions and every existing
center, stationary-pose, derivative and nonlinear-containment path. Require
exact agreement with all 348 saved integer-implementation bounds. Component
tests additionally compare every original report field with tracing enabled.

Record a snapshot every 128 packets and at the final used packet. Retain source
and force remainders, the velocity increment, accumulated residual velocity,
coordinate departure and rotation bounds. Nested bounds overlap; they are not
independent physical errors and must not be added as such.

## Separate finite allowance

24 fixed identities; 78 native oracle calls and 19,632 packet visits; 348
propagation bounds and 60,288 logical steps. Reserve 348 source and derivative
setups, 7,536 appends/body bounds and at most 32 snapshots per propagation
bound: 11,136 snapshots maximum. No trace calls a new trajectory or derivative
oracle. Four workers with one numerical thread each; 60 seconds per bound and
600 seconds overall, enforced cooperatively.

No retries, allowance expansion, process signals, aircraft originals, observed
fits or protected ESA data. Freeze source, inputs, compiler and environment.
Passing qualifies tracing on the control matrix only. A later finite diagnostic
must retain the original selected generated sources and its own work limits.
