# Repeat fitted predictions with fresh noise

**The 48-start diagnostic pilot is running.** It repeats the two-minute
calibration-and-prediction procedure with two preassigned fresh noise seeds.
Calibration is estimated again for every start, using only the earlier
observations. Later positions are kept for scoring.

Both input formats, all three generating/fitted candidates, both processing
assumptions and both starts are retained. Each case is generated under its named
candidate and fitted with that same candidate. This is a software experiment,
not another comparison of Earth's shape or a new aircraft-data result.

The [native composition gate](../prediction-score-qualification/native-composition-qualification/README.md)
passes 42 software checks; 33 separate lifecycle checks pass. The pilot preserves
the original fit limits, calibration bounds and physical accuracy screens. All
failed and unavailable outcomes will remain in the report.

Two numerical threads run within a fixed four-hour cooperative ceiling.
The two fresh seeds can reveal instability; they cannot establish a tail
quantile, calibrated uncertainty or a detection. Reserved ESA groups are not used.
