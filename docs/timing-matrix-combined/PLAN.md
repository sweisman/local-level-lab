# Saved-only audit of complete matrix coverage

This audit runs no fits and uses no new observations. It joins the 44 completed
cases from the interrupted matrix with the four cases from its separate
completion controls. It preserves both constituent studies' original states.

Before accepting combined qualification, independently audit both saved
publications using their existing numerical, physical, repeat and replay checks.
Bind their exact completion hashes. Require all 241 common execution sources
to match, all current auditor dependencies to match the completion freeze, and
identical numerical environments. Reject missing or duplicated case coverage,
numerical failures, source changes and environment changes.

The combined result must contain all 48 original computational payloads exactly
once, all 24 complete paired-start comparisons and all four original input,
training-observation and error-operator replays. Three replay cases come from
the earlier 44 fits; one comes from the separate completion. Their reference
records must be unchanged. Do not select among alternative fitted results.

Qualify the assembler against deliberate missing-case, duplicate-case, failed-fit,
failed-pair, replay, hash, source and environment errors before using it. Bind
that software qualification to its source and environment. Publish the combined
coverage table, provenance and preserved interruption records without copying
worker trees or refitting.

A pass establishes generated-data optimizer coverage under the declared error
law. It does not establish an aircraft confidence level, reopen a closed
calibration allowance, or make the interrupted study successful. A future
calibration needs a separate finite review and disjoint cohorts.
