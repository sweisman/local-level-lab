# Selected-stretch analysis: final summary pending

The analysis is still running. All 232 retained files have been screened, yielding
53 eligible stretches totaling 424.3 minutes. These include overlapping instrument
streams and are not 53 independent flights.

This page will be replaced automatically after the complete results pass their publication
audit. The summary will report:

- Converged, unresolved and failed fits for each Earth model and each processing assumption.
- Fully converged versus unresolved stretches: counts, duration, ground speed and IMU types.
- Residuals, parameter-limit hits and use of the computational allowance in both groups.
- Each source filename/hash, logged IMU type, UTC interval, duration, receiver ground speed
  and track length, with the selected GPS track points available separately.
- Available matched shape comparisons in indeterminate stretches, showing which models
  converged and how those pairs lean without treating unfinished fits as losing models.
- Globe, flat or unknown outcomes, followed by rotation comparisons only for resolved globe results.
- Remaining assumptions and the distinction between numerical preferences and scientific evidence.

Every eligible stretch will remain represented. Unfinished fits will not be counted as
evidence against their models. No new fitting is performed to generate this summary.
