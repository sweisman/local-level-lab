# Bounded timing adapter

This adapter addresses packet-boundary stopping failures among the six unresolved
stretches. It locates a local timing-gradient crossing, verifies the actual packet
intervals, then checks both sides with all nuisance directions included.

The [qualification plan](PLAN.md) fixes the software controls and computation
limits. Results will be preserved in RESULTS.md. This study contains no archival
fits and cannot change the current findings.
