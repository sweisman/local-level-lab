**In plain words.** GPS receivers on one aircraft can share an error. This page asks how large such a shared error would have to be to change the NASA forecast results. On the three flights with complete forecasts, an added shared error of 1.7 to 8.2 m per report would push the best forecast to its 10 m limit. Changing which model ranks first would take 39 to 63 m. These are sizes of error that would matter, not measurements of the actual error, which remains open.
