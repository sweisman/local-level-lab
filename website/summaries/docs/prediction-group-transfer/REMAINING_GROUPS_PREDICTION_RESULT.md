**In plain words.** This extends the forecast test to 20 NASA flight groups, using the globe with the specified field only. In 9 of 20 groups the later position errors stayed within the fixed reference from the earlier tests. The other 11 could not be scored because the fit failed its numerical check, and those failures are kept in the record. This study does not compare Earth shapes. The groups come from the same archive, so it is a development test, not independent confirmation.
