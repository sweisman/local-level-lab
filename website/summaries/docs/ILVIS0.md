**In plain words.** This is the guide to the NASA flight files the project uses. NASA's Operation IceBridge survey aircraft carried motion sensors (gyroscopes and accelerometers) and GPS receivers. The files hold three things: the raw sensor readings, a GPS track, and a navigation solution the instrument computed on board by combining them. The page explains how each was identified. The comparisons use the raw readings and the GPS track. The on-board solution is used only to check the decoding and to screen for steady flight.
