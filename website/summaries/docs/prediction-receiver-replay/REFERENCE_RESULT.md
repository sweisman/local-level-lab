**In plain words.** To judge a real forecast, you need to know how large forecast errors are when the model is right. This page builds that reference from saved simulated forecasts, without rerunning any fit. It recovered 3,432 reference scores from 286 of 299 planned runs. The 13 missing runs limit how fine a ranking can be claimed. These figures describe errors in the simulator. Calibration for real aircraft needs separate tests.
