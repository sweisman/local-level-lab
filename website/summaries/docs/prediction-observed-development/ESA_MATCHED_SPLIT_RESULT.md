**In plain words.** A forecast test is only fair if the positions to be predicted are kept away from the fit. This page checks the software that prepares the inputs. Two fits of different lengths, 400 and 800 GPS reports, end at the same moment and predict the same 120 later times. The later positions never reach the fitting input: a test that put invalid text in those fields left the fit inputs unchanged. A first attempt stopped on a software error and is kept in the record alongside the corrected one.
