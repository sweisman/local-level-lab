**In plain words.** This page gathers the checks made against three GPS stations on the ground, which saw the same satellites at the same time as the aircraft. The ground stations check some errors that the aircraft's receivers share. Errors specific to the aircraft and its antenna remain open. All of this concerns one development flight. The seven reserved flights are untouched.

*Background: one two-minute comparison on the ESA development flight scores the competing Earth models using millimetre-level satellite-range measurements. "The gap" is the difference between their scores.*
