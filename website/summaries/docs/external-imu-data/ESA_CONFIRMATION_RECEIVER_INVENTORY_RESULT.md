**In plain words.** Seven ESA flight groups are held back to test a fixed method later. This page finds which parts of them could be used, looking at GPS data only. It identifies ten provisional windows, 22.5 to 346.7 minutes long, with at least one in every group. No motion-sensor data from the reserved flights and no Earth-model result was used. The windows are provisional: sensor timing and completeness still have to be verified for each before it can be selected.
