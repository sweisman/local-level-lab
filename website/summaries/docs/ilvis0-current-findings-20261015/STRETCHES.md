**In plain words.** Each row below is one stretch of steady, high-speed flight from NASA's Operation IceBridge surveys. The motion recorded on each stretch was fitted under a globe and under a flat disc. All 53 stretches favored the globe.

How to read the table:

- **Source recording / stretch ID.** The NASA file the stretch comes from, and a short code for the stretch.
- **UTC interval.** When it was flown.
- **IMU type.** Which sensor configuration recorded it. An IMU (inertial measurement unit) contains gyroscopes and accelerometers.
- **Minutes** and **ground speed.** How long the stretch lasted, and its lowest and median GPS speed. Every stretch is at least four minutes long at 700 km/h or more.
- **Mean course.** The direction of travel over the ground: 0° is north, 90° east, 180° south.
- **Latitude.** Where it was flown. Negative values are south of the equator.
- **Track.** The distance covered, given for description only.
- **Current disposition.** The outcome: which model fitted the recording better.

Several stretches can come from the same flight, so these are not 53 independent flights. They fall into [27 recording groups](../analysis-provenance/NASA_GROUP_EVIDENCE.md).
